# 3DPPM Community

🌐 **Language / Sprache:** [🇩🇪 Deutsch](README.md) | **🇬🇧 English**

Welcome to the community for **3D-Print Profile Management (3DPPM)**.

3DPPM is a software application for managing, optimizing, and evaluating 3D printing profiles. It helps users systematically test printing settings, document results, and develop optimized printing profiles for different printers, filaments, and printing requirements.

The goal of 3DPPM is to make 3D printing optimization transparent, reproducible, and efficient.

## Downloads and Release Notes

[Download public releases and view release notes](https://github.com/speedy764/3DPPM-Community/releases)

Only **public releases** are provided. New versions are announced directly within 3DPPM. The application includes an integrated update feature that allows users to install available updates directly from 3DPPM.

## Help and Documentation

- [Getting Started, Backups and Updates](docs/ERSTE_SCHRITTE.md)
- [Community Contribution Guidelines](CONTRIBUTING.md)
- Comprehensive documentation is available directly within 3DPPM through the integrated Help feature.

When reporting a bug, always include the 3DPPM version you are using.

Only share information necessary to describe the issue. Never include passwords, access tokens, personal information, or complete databases in public issues.

## Development

This repository serves as the **public community and support platform** for 3DPPM users.

Application source code development takes place separately in a private repository.

Bug reports, feature requests, and feedback are collected and discussed here. Decisions regarding implementation and integration into future releases are made by the project maintainers.
