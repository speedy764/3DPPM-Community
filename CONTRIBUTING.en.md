# Contributing to the 3DPPM Community

🌐 **Language / Sprache:** [🇩🇪 Deutsch](CONTRIBUTING.md) | **🇬🇧 English**

You can help shape 3DPPM by reporting bugs, sharing your experience with the application, asking questions, and requesting features.

## Create an Appropriate Issue

1. Check **Issues** to see whether your topic has already been raised. If it has, add to the existing issue whenever possible.
2. Use the **Bug Report**, **Feature Request**, or **Question** template.
3. Keep each issue focused on one related topic.
4. When responding to follow-up questions, use the same issue whenever possible.

For bugs, include the exact application version, the steps leading to the error, and the expected and actual behavior. For feature requests, describe the problem you want to solve and the intended benefit.

## Public Information

Issues and their attachments are public. Remove passwords, access tokens, personal information, and confidential content from descriptions, screenshots, and logs. Do not upload a complete production database.

## Interacting with Others

Please remain constructive and respectful. Different workflows and experiences help improve the application.

## From Feedback to Implementation

The project maintainers review and discuss submitted topics. Follow-up questions and decisions may be recorded in the issue. Submitting a feature request does not guarantee a particular scope or delivery date.

Source code development takes place separately. This repository is for the community, downloads, and user documentation.
