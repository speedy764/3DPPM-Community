# Getting Started with 3DPPM

🌐 **Language / Sprache:** [🇩🇪 Deutsch](ERSTE_SCHRITTE.md) | **🇬🇧 English**

## Download and Launch

1. Open the [Releases](https://github.com/speedy764/3DPPM-Community/releases).
2. Select a published release and read its release notes.
3. Download the ready-to-use portable build package provided with that release.
4. Extract the entire package into a writable folder and launch `3DPPM.exe`.
5. Follow the included startup instructions and open the Help in 3DPPM if needed.

If the releases do not contain a build package yet, no public version has been made available.

## Back Up Your Data

Before updating, create a backup using the backup feature available in your version. Also back up your personal settings and any files or images you have created. Store the backup outside the folder whose application files will be replaced.

When using a central MySQL database, restoring a backup affects the shared data used by all users. Coordinate this work with the other users or the responsible administrator.

## Updates

Follow the instructions in the release notes for the specific build. For a portable installation, do not replace only the EXE: the included runtime files belong to the corresponding application version.

If your installed version already includes an update wizard, you can use its guided update process. Follow the instructions about backups, the database schema, and closing other clients. Earlier versions may require a one-time manual update of the entire application folder.

The public release source is `speedy764/3DPPM-Community`.

## Help and Feedback

You can access the detailed user documentation through the Help button in 3DPPM.

Use the [issue templates](https://github.com/speedy764/3DPPM-Community/issues/new/choose) to submit feedback. When reporting a bug, include the exact version. Describe what you did, what you expected, and what actually happened.
